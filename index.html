01. about

I'm a Digital Agriculture student at Olds College — my time is spent in the field or in the office analyzing the data. I work summers at the Olds College Centre for Innovation collecting data via drones, soil probes, GPS equipment, and many more sensors. But my favourite part is then making sense of all that data. That gap between unusable raw field data and something actually useful is what drives most of my work.

Right now I'm building RETA, an open-source toolkit for cleaning agricultural geospatial data such as soil and yield data, and its machine learning extension RETA_ML, which uses graph neural networks to detect spatial outliers in field sensor data. They anchor a family of eight open-source tools I've built for field-data workflows — from drone-imagery sorting (Perch) to weekly crop-monitoring deliverables (Magpie).

Based in Carstairs, Alberta.

RETA

Unified framework for cleaning yield monitor and spatial agricultural data — removes operational, global, and local errors via a sequential CRS-aware pipeline, deployable as a QGIS Processing plugin or headless Python script.
// pipeline
3-phase sequential filtering: Operational → Global → Local errors
CRS-aware distance & area via pyproj (falls back to WGS84 Haversine)
Auto-detection for speeds, delays, turn threshold, and AOI bounds
Global outlier margin (0–1) widens AOI bounds when Auto-Yield Limits is on
// integration
QGIS Processing Toolbox — V8 Sequential algorithm
Headless mode via data_cleaner.py — no QGIS runtime required
Manual correction dock + advanced annotation tools included
// output
Filtered layer with filtering_category + error_reason per point
Colour-coded: Red=Operational, Orange=Global, Yellow=Local, Green=Clean
PythonQGISGeoPandaspyprojSpatial Analysis

// research — 2025 — presented at ICPA/ConBAP 2026

RETA_ML

GNN-based outlier detection built on the RETA pipeline — classifies yield monitor errors into 4 categories using a HeteroGAT model with temporal, spatial, and transect graph edges. No QGIS dependency; pure Python/GeoPandas preprocessing.
// architecture
HeteroGAT with 3 edge types per field: temporal, spatial (BallTree), transect
4-class output: Clean, Operational Error, Global Outlier, Local Outlier
ThreeGNNEnsemble ablation — three independent GAT stacks, late fusion
Directional variogram used to suggest spatial radius R from data
// training
Masked hierarchical focal loss — single 4-class head, phase-ordered
Temperature scaling calibration; ECE reported before and after
Optuna sweep: focal γ/α, hidden_dim, heads, dropout, lr, weight_decay
Uncertainty flagging via entropy of calibrated class probabilities
// evaluation
Baselines: RETA threshold pipeline + XGBoost (no graph, same features)
Per-class P/R/F1 + macro F1; confusion matrices per run
K-means spatial split — augment train only, normalize train/val
// published results
Poster + paper at the 17th ICPA / 11th ConBAP, Porto Alegre, Brazil (Jul 2026)
~50,000-point annotated dataset across 3 sensors (EM38, Veris 3100, GreenStar)
Leave-one-sensor-out CV: tree-ensemble baselines (RF/XGBoost) reproduce clean readings well (F1 = 0.95) but transfer poorly on local spatial anomalies (F1 = 0.30)
That spatial-transfer gap is the direct motivation for RETA_ML's graph-based approach
PyTorchPyGHeteroGATXGBoostOptunaGeoPandas

Plover

06. research & publications

----[ presented work ]----
[^]

A Machine Learning Framework for Automated Anomaly Detection in Precision Agriculture Geospatial Data

Poster presentation — 17th International Conference on Precision Agriculture & 11th Brazilian Congress on Precision and Digital Agriculture (ICPA/ConBAP) — Porto Alegre, Brazil
With Felippe H. S. Karp (Olds College). Built an expert-annotated, ~50,000-point dataset spanning three sensors (EM38, Veris 3100, GreenStar combine yield monitor) and evaluated Random Forest and XGBoost under leave-one-sensor-out cross-validation. Clean readings transferred reliably (F1 = 0.95), operational errors transferred moderately (F1 = 0.52) — but local spatial anomalies transferred poorly (F1 = 0.30), since tree-ensemble models don't represent spatial neighbourhood structure. That gap is the direct research motivation behind RETA_ML's graph neural network approach. Funded by an NSERC CCI Mobilize Grant.
Jul 2026
